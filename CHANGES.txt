DivumWX - Earthquake map: same colours as the Equal Earth map (for 2.0.0)
=========================================================================

Goes on top of version-2.0-beta at 7deddd1 ("Boltek patch"). This package
includes the Equal Earth conversion, so if you have not copied in the
earlier earthquake-equal-earth package, you can skip it and use this one.

What changed
  - The map in modalEarthquakeMap.html now loads css/equalEarthMap.css,
    the same stylesheet the Equal Earth map uses, and takes its ocean,
    land, coast, grid, rim, night and station colours from it. If you
    change a colour there, both maps change together.
  - It shades the night side the same way as the Equal Earth map: four
    twilight steps around the point opposite the sun, worked out for the
    time you open it. This was the main reason the two maps looked
    different.
  - It uses the same coastlines (jsondata/countries-110m.json, already in
    your repo) instead of worldmap.json.
  - The map sits on the card background, like the Equal Earth map.
  - The station dot has a card-coloured outline, and its name has a halo
    so it can be read over the night shading.
  - Earthquake dots and the timeline are unchanged.

Files are laid out at their repo paths. Copy each one over the version in
your repo:
  divumwx/modalEarthquakeMap.html   version 1.1.1
  CHANGELOG.md                      earthquake entry
No WeeWX restart needed; reload the dashboard.

Using git instead, on version-2.0-beta (7deddd1):
  git apply earthquake-equal-earth.patch

Clean-up reminder: the repo root still has CHANGES.txt,
windy-radar-card.patch, windy-test.html and boltek-lightning.patch from
earlier packages. The installer copies every file in the repo root into
users' WeeWX folder, so delete them from the repo (and don't commit this
CHANGES.txt or the .patch either).
