DivumWX - Windy Radar card: centring fix (for 2.0.0)
====================================================

Goes on top of version-2.0-beta at 7b18276 (the v2 Windy package).

What changed
  - Removed Windy's "marker=true" option from the card and the larger
    map. In Windy's embed it marks the viewer's own location (worked out
    from their IP address), not the station.
  - Windy's map now loads only once it's on screen and laid out, on both
    the card and the larger map. Windy can centre in the wrong place if
    it loads while hidden or before it has its final size. The card's
    15-minute refresh and unit-change reloads wait the same way.
  - The larger map's footer now says what it's centred on, e.g.
    "Centred on 51.937, -0.982 (weewx.conf [Station] latitude/longitude)."
    If the map is ever off again, this shows whether the coordinates or
    Windy are at fault.

Files are laid out at their repo paths. These 6 are the only ones that
differ from your branch; copy each over the version in your repo:
  divumwx/cardsBundleNew.js        cardWindyRadar: no marker, deferred load
  divumwx/modalWindyRadar.html     no marker, deferred load, coords shown
  divumwx/index.html               bundle ?v=5baef93b
  divumwx/hyperIndex.html          bundle ?v=5baef93b
  divumwx/lexendIndex.html         bundle ?v=5baef93b
  CHANGELOG.md                     entry updated

Using git instead, on version-2.0-beta (7b18276):
  git apply windy-radar-card.patch

Reminder: the repo root still has a CHANGES.txt from an earlier package.
The installer copies every file in the repo root into users' WeeWX
folder, so you'll probably want to delete it from the repo.
