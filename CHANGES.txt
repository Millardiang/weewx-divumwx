DivumWX - Windy Radar card, title-link version (for 2.0.0)
==========================================================

This replaces the RainViewer "Weather Radar" version now on
version-2.0-beta (edeb26f). No RainViewer, no CARTO, nothing to sign up
for: the card and the larger map use only Windy's embed.

What changed
  - The card's map is live, so visitors press Windy's own play arrow on
    the card to animate the radar, and can pan and zoom it.
  - Only the card's title opens the larger map. Hovering over the title
    shows: "Click the title to open the larger Windy map. Press [play] on
    the map to animate the radar."
  - The larger map is 50% bigger: 1350 x 900 (was 900 x 600). On shorter
    windows the map shrinks so the whole modal still fits.
  - The card can still be dragged by its title bar; the map itself takes
    the mouse, so dragging from the map pans the map instead.

Files are laid out at their repo paths. These 8 are the only ones that
differ from your branch; copy each over the version in your repo:
  divumwx/cardsBundleNew.js        Windy card with title link, bundle 1.1.0
  divumwx/modalWindyRadar.html     1350 x 900, fits shorter windows
  divumwx/index.html               bundle ?v=1742a3e8, original card tooltip
  divumwx/hyperIndex.html          bundle ?v=1742a3e8, original card tooltip
  divumwx/lexendIndex.html         bundle ?v=1742a3e8, original card tooltip
  skins/DivumWX/lang/en.conf       "Weather Radar" string removed
  skins/DivumWX/lang/en_US.conf    "Weather Radar" string removed
  CHANGELOG.md                     entry describes this version
install.py and build_card_bundle.py on your branch are already right.

Using git instead, on version-2.0-beta (edeb26f):
  git apply windy-radar-card.patch

Note: your repo root now has a CHANGES.txt from the last package. The
installer copies every file in the repo root into users' WeeWX folder,
so you'll probably want to delete it from the repo rather than replace
it with this one.

To see the card on an existing install, add cardWindyRadar to
enabled_cards under [DivumWXCards] in weewx.conf and restart WeeWX.
